Este documento é a fonte de verdade da identidade visual do portfólio fotográfico de José Cunto Neto. Toda nova seção, página ou componente deve seguir rigorosamente os tokens, padrões tipográficos e comportamentos descritos aqui. Nenhum estilo deve ser inventado — somente os padrões já consolidados no projeto devem ser utilizados.

01

Paleta de Cores

Ink --ink #18181b · rgb(24, 24, 27)

Texto principal, fundos do menu mobile, overlays, ícones activos, bordas hover do CTA

Ink Mid --ink-mid #71717a · rgb(113, 113, 122)

Links de navegação, texto CTA, eyebrows, labels de capítulo (num + tag), texto de meta

Ink Light --ink-light #a1a1aa · rgb(161, 161, 170)

Scroll label, hyear, pf-header__meta, mobile nav meta, nav hover opacity target

Ink Xlight --ink-xlight #d4d4d8 · rgb(212, 212, 216)

Bordas do CTA em repouso, linhas divisórias, bordas de elementos sutis

Background --bg #fafafa · rgb(250, 250, 250)

Fundo da página, texto sobre fundos escuros (CTA hover), fill do nav scrolled

Nav Blur rgba(250,250,250,.88) + backdrop-filter: blur(24px) saturate(1.4)

Fundo da navegação no estado .scrolled — nunca usar sem backdrop-filter

O projeto utiliza escala monocromática estrita. Nenhuma cor de acento (azul, verde, vermelho) existe no sistema. Toda cor deve ser derivada das 5 variáveis acima.

04

Animações & Transições

Curvas de Easing

--expo (Principal) cubic-bezier(0.16, 1, 0.3, 1)

Usada em: clip-path de imagens, nav transitions, CTA hover, mobile menu, scroll line. Duração típica: 0.4s–1.5s.

ease (Secundária) ease

Usada em: hover opacity da logo, transições de cor de links. Duração: 0.3s.
